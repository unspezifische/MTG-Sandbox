This is mainly intended as an add-on service for [Kachhapa- the World Turtle|https://github.com/unspezifische/Kachhapa--The-World-Turtle], which is itself a TTRPG campaign manager. The MtG Web App is intended as a stand-along service, using the same database backend and routing already provided by Kachhapa, to enable user to build their own Magic decks, along with a plethora of resources for examining deck metrics, goldfishing capabilities, simulating games using heuristic AI, and playing against other players in realtime. Since an important part of learning is from mistakes, games are saved and stored in a way that allows players to review a match afterwards and find clues they missed or, with the assistance of the heuristic AI, test alternate methods for dealing with opponents to explore different branches of how a match *could* have gone instead.
